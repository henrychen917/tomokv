The first stream-preservation extension (runs nDAi1z and hKBxjs) passed the TCP oracle, but used a 16 KiB SO_RCVBUF which made draining a 7.5 MiB reply take minutes. The two owned Python drivers were interrupted before the aggregate row watchdog expired. The revised check uses the default receive window and still requires CLIENT LIST omem > 0 before waiting seven seconds. No RSS threshold, timeout budget, data assertion or required leg was widened or skipped.
