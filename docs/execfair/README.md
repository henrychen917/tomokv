- `dispatch-instructions/comparison.json` traces the actual linked production `exec_batch_prefetched` entry, using both original main objects in their production link order (only the program entry symbol is renamed). All 24 GET/SET/INCR comparisons differ: POST adds 6 instructions per operation in 1s and 2 in 2s, in both database implementations and at batch 1/32. Its changed MULTI branch is the inferred cause of compiler frame/register changes; the fused body gains a 32-byte stack-alignment prologue, as recorded in `changed-prologues.json`. Atomic 1, slowlog -1 and read-local 0 are recorded. The promised full command-scope zero-cost identity is **not met**. Fixture glue and external library internals are excluded; replies are checked exactly after each bounded batch. Counts are not hardware measurements or rate claims.

All 24 GET/SET/INCR comparisons match PRE, including per-body totals. This atomic-0 scope contains production plain-write admission, the handler, and completion; it excludes executor dispatch, fixture setup and external allocator/library internals. It must not be substituted for the broader dispatch result above. Raw traces for both scopes are compressed with checksum inventories.
