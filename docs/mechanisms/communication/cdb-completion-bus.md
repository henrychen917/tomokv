# `cdbSlotPublish` / `cdbSlotReady` / `cdbSlotClear` — EX-to-IO reply-ready completion bus

## What it is

The completion bus is a per-real-client array of one-byte ready flags. An executor publishes `1` in the flag selected by a fake client's captured CDB index and fake-ring slot; the real client's owning IO thread polls that same flag before consuming the fake's reply and then clears it to `0`. The three operations are `cdbSlotPublish`, `cdbSlotReady`, and `cdbSlotClear`. ([src/server.c:3149-3168](../../../src/server.c#L3149-L3168))

For ordinary worker jobs this is the return channel paired with the IO-to-EX [`exQueue` SPSC ring](ring-push-pop.md): dispatch publishes the fake, including `fake->cdb` and `fake->fake_slot`, through the ring's release-store of `tail`; completion publishes the worker-written reply and lifetime state back through the ready byte. ([src/server.c:8591-8604](../../../src/server.c#L8591-L8604), [src/server.c:20960-20968](../../../src/server.c#L20960-L20968), [src/server.c:22242-22263](../../../src/server.c#L22242-L22263))

## Exact representation and footprint

`cdbSlots` has exactly two fields:

| Field | Type and extent | Ownership and role |
| --- | --- | --- |
| `ready` | `redisAtomic uint8_t ready[TOMO_PIPELINE_DEPTH_MAX]`; the maximum is `32`. | One independent ready byte for each possible fake-ring slot. ([src/server.h:1558-1559](../../../src/server.h#L1558-L1559), [src/server.h:1638-1643](../../../src/server.h#L1638-L1643)) |
| `_pad` | `char[CACHE_LINE_SIZE - sizeof(redisAtomic uint8_t) * 32]`. | Extends the object to one cache line. ([src/server.h:1639-1643](../../../src/server.h#L1639-L1643)) |

The source asserts that a ready atomic is exactly one byte, that atomic characters are always lock-free, and that `sizeof(cdbSlots) == CACHE_LINE_SIZE`; the type itself is cache-line aligned. ([src/server.h:1643-1649](../../../src/server.h#L1643-L1649)) The C11 atomic implementation expands `redisAtomic` to `_Atomic`; the declaration remains `redisAtomic uint8_t` in the structure. ([src/atomicvar.h:90-98](../../../src/atomicvar.h#L90-L98), [src/server.h:1639-1640](../../../src/server.h#L1639-L1640))

`CACHE_LINE_SIZE` is 128 bytes only for Apple AArch64 and 64 bytes otherwise unless overridden. Consequently, one bus is exactly 128 bytes with 96 pad bytes on Apple AArch64, or 64 bytes with 32 pad bytes on the default branch. ([src/config.h:38-44](../../../src/config.h#L38-L44), [src/server.h:1640-1649](../../../src/server.h#L1640-L1649))

A real client owns an aligned array of `ncdb` buses through `clientTail(c)->reply_cdb`; that pointer is the first field of `clientExecTail`, and the source asserts its zero offset within the tail. ([src/server.h:1778-1786](../../../src/server.h#L1778-L1786), [src/server.h:1949-1957](../../../src/server.h#L1949-L1957)) The live bus span is exactly `ncdb * CACHE_LINE_SIZE` bytes. Allocation requests `ncdb * sizeof(cdbSlots) + CACHE_LINE_SIZE + sizeof(void *)` bytes, rounds the usable base upward to a cache-line boundary, and stores the raw allocation pointer immediately before that base. ([src/networking.c:629-639](../../../src/networking.c#L629-L639)) Thus the requested allocation is the live span plus one cache line plus one pointer; the extra bytes provide alignment slack and the recovery word. ([src/networking.c:629-639](../../../src/networking.c#L629-L639))

Every `cdbSlots` array element therefore begins on its own line. Different CDB indices never share a completion line, while all 32 slot bytes within one CDB deliberately share that CDB's line. ([src/server.h:1639-1649](../../../src/server.h#L1639-L1649), [src/networking.c:635-643](../../../src/networking.c#L635-L643)) Fakes do not allocate a bus: reset sets their `reply_cdb` pointer to `NULL`, records the real parent, and all helpers address the parent's bus. ([src/networking.c:180-185](../../../src/networking.c#L180-L185), [src/server.c:3158-3168](../../../src/server.c#L3158-L3168))

## CDB and slot addressing

At startup the server chooses `num_cdb = num_workers` when `detectL3Domains() > 1`, otherwise `1`, then clamps the result to `num_workers`, `NUM_CDB_MAX` (`256`), and a minimum of one. ([src/server.c:6094-6107](../../../src/server.c#L6094-L6107), [src/server.h:1638](../../../src/server.h#L1638)) The worker and IO compile-time limits are both 128, so the current initialization makes the effective mapping either one shared bus or one bus per worker; the generic modulo fallback remains in `cdbIndexFor`. ([src/server.h:1468-1487](../../../src/server.h#L1468-L1487), [src/server.c:3141-3146](../../../src/server.c#L3141-L3146))

`cdbIndexFor(ex_id)` returns `0` when `num_cdb == 1`, returns `ex_id` when `ex_id < num_cdb`, and otherwise returns `ex_id % num_cdb`. ([src/server.c:3141-3146](../../../src/server.c#L3141-L3146)) Express dispatch, the indivisible T6 branch, and general worker dispatch all capture `cdbIndexFor(the selected worker)` in `fake->cdb` before enqueueing the fake. ([src/server.c:8499-8512](../../../src/server.c#L8499-L8512), [src/server.c:8591-8604](../../../src/server.c#L8591-L8604)) Each worker independently caches `cdbIndexFor(worker->id)` in `exSliceCtx.wcdb`; ordinary batch completion uses that cached index, relying on the dispatch-to-worker invariant that `fake->cdb == wcdb`. ([src/server.c:21673-21685](../../../src/server.c#L21673-L21685), [src/server.c:21720-21729](../../../src/server.c#L21720-L21729), [src/server.c:22242-22252](../../../src/server.c#L22242-L22252))

The slot is `dispatchid & ring_mask` when the IO thread takes a fake-ring entry, and the resulting index is copied into `fake->fake_slot`. ([src/server.c:8423-8434](../../../src/server.c#L8423-L8434)) The IO thread refuses another non-stateful dispatch when `dispatchid - flushid == ring_size`, so a live generation cannot be overwritten. ([src/server.c:8280-8282](../../../src/server.c#L8280-L8282), [src/server.c:8314-8326](../../../src/server.c#L8314-L8326)) On drain, the address is reconstructed as `slot = flushid & ring_mask` and paired with that fake's captured `cdb`. ([src/server.c:4148-4152](../../../src/server.c#L4148-L4152), [src/server.c:4236-4241](../../../src/server.c#L4236-L4241))

## State machine and memory ordering

| Transition | Code operation | Ordering and payload |
| --- | --- | --- |
| Allocate / arm | Store `0` into all `ncdb * 32` bytes. | `memory_order_relaxed`; no generation is visible yet. ([src/networking.c:635-643](../../../src/networking.c#L635-L643)) |
| Complete | `cdbSlotPublish(real, cdb, slot)` stores `1`. | `memory_order_release`; this publishes the fake's prior reply-buffer and lifetime-state writes. ([src/server.c:3154-3164](../../../src/server.c#L3154-L3164)) |
| Poll | `cdbSlotReady(real, cdb, slot)` acquire-loads and tests nonzero. | `memory_order_acquire`; observing `1` makes the publisher's preceding writes visible. ([src/server.c:3154-3160](../../../src/server.c#L3154-L3160)) |
| Retire / re-arm | `cdbSlotClear(real, cdb, slot)` stores `0`. | `memory_order_relaxed`; clearing publishes no payload. Any subsequent observed `1` is independently release-published, either after a later worker stage is published through its queue or directly by a completion path such as `csMsetInstallDone`. ([src/server.c:3151-3168](../../../src/server.c#L3151-L3168), [src/server.c:10372-10395](../../../src/server.c#L10372-L10395), [src/server.c:10418-10425](../../../src/server.c#L10418-L10425), [src/server.c:14554-14561](../../../src/server.c#L14554-L14561)) |

The ordinary worker executes a popped batch first, records each ordinary fake's `(parent, slot)`, and only after execution release-stores every corresponding ready byte; the source treats each store as the worker's final access to that saved parent. ([src/server.c:22053-22061](../../../src/server.c#L22053-L22061), [src/server.c:22208-22252](../../../src/server.c#L22208-L22252)) The worker then release-publishes the queue's batch-retirement frontier, so ready publication precedes retirement publication in program order. ([src/server.c:22248-22263](../../../src/server.c#L22248-L22263))

`handleWorkerReplies` first flushes staged request queues, then walks each real client's fake ring from `flushid` toward `dispatchid`. It stops at the first acquire-load that returns not-ready, so later ready replies cannot pass an earlier incomplete reply. ([src/server.c:4120-4129](../../../src/server.c#L4120-L4129), [src/server.c:4236-4241](../../../src/server.c#L4236-L4241)) For a ready live connection it reassembles or splices the reply, clears the byte, retires the fake, and increments `flushid`; the connection-closing path likewise waits, clears, retires, and increments without writing the reply. ([src/server.c:4148-4208](../../../src/server.c#L4148-L4208), [src/server.c:4271-4341](../../../src/server.c#L4271-L4341))

Multi-stage cross-shard operations reuse the same head slot as a stage-ready signal. On a branch that launches another worker stage, its IO-side continuation clears the old ready generation before its first push, so a subsequent worker release-store cannot be clobbered by a late clear. ([src/server.c:14554-14561](../../../src/server.c#L14554-L14561)) The pipe, sort, generic-hop, MSETNX-reservation, and repushing atomic-NX branches follow that clear-before-repush pattern. ([src/server.c:12716-12744](../../../src/server.c#L12716-L12744), [src/server.c:12845-12893](../../../src/server.c#L12845-L12893), [src/server.c:13376-13484](../../../src/server.c#L13376-L13484), [src/server.c:14214-14239](../../../src/server.c#L14214-L14239), [src/server.c:14556-14568](../../../src/server.c#L14556-L14568), [src/server.c:14799-14808](../../../src/server.c#L14799-L14808)) A terminating incomplete atomic group or NX-present branch instead clears and enters `csMsetInstallDone`, whose FIFO completion path can directly release-publish the CDB byte; it does not repush that group through an SPSC job queue. ([src/server.c:10336-10401](../../../src/server.c#L10336-L10401), [src/server.c:10418-10426](../../../src/server.c#L10418-L10426), [src/server.c:12832-12844](../../../src/server.c#L12832-L12844))

## Producers, consumer, and direct callers

An owning worker is the usual `0 -> 1` producer, and the real client's owning IO thread is the sole `1 -> 0` clearer for a slot generation; slot reuse waits for that clear. ([src/server.c:3149-3157](../../../src/server.c#L3149-L3157), [src/server.c:22144-22205](../../../src/server.c#L22144-L22205), [src/server.c:22242-22252](../../../src/server.c#L22242-L22252)) The inline execution branch assigns CDB 0, executes synchronously on the IO thread, and calls `cdbSlotPublish` so delivery still goes through the in-order drain. ([src/server.c:8605-8640](../../../src/server.c#L8605-L8640)) IO-side abort/NX continuations can also enter `csMsetInstallDone`, whose successful FIFO drain publishes the group head; the invariant is one `0 -> 1` publisher for the current generation, not that every publication instruction executes on an EX thread. ([src/server.c:4160-4199](../../../src/server.c#L4160-L4199), [src/server.c:4275-4307](../../../src/server.c#L4275-L4307), [src/server.c:10336-10401](../../../src/server.c#L10336-L10401), [src/server.c:10418-10426](../../../src/server.c#L10418-L10426), [src/server.c:12832-12844](../../../src/server.c#L12832-L12844))

## Enforced invariants

- A ready byte has one publisher and one clearer for a slot generation; the use of separate atomic bytes avoids a shared bitmap read-modify-write. ([src/server.h:1626-1637](../../../src/server.h#L1626-L1637), [src/server.c:3149-3152](../../../src/server.c#L3149-L3152))
- The worker's release-store of `1` and the IO thread's acquire-load of `1` are the payload handoff; the relaxed clear is not a payload handoff. ([src/server.c:3154-3168](../../../src/server.c#L3154-L3168))
- A fake's CDB index is captured before its queue publication in the express, T6, and general worker branches, and an ordinary worker uses the same `cdbIndexFor(worker id)` value for completion. ([src/server.c:8499-8512](../../../src/server.c#L8499-L8512), [src/server.c:8591-8604](../../../src/server.c#L8591-L8604), [src/server.c:21681-21685](../../../src/server.c#L21681-L21685), [src/server.c:21722-21729](../../../src/server.c#L21722-L21729))
- The drain consumes only a contiguous ready prefix and clears before final slot reuse or before a multi-stage repush. ([src/server.c:4236-4241](../../../src/server.c#L4236-L4241), [src/server.c:4334-4341](../../../src/server.c#L4334-L4341), [src/server.c:14554-14561](../../../src/server.c#L14554-L14561))
- A real client is not freed while its fake ring is in flight; once `dispatchid == flushid`, teardown frees the raw allocation recovered from immediately before `reply_cdb`. ([src/networking.c:2703-2718](../../../src/networking.c#L2703-L2718), [src/networking.c:2725-2738](../../../src/networking.c#L2725-L2738))
