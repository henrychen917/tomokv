# Control plane — current pointers

The pre-R7 scheduler draft is retired. See [round3-read/reorder.md, section A](../round3-read/reorder.md#a-as-built). The shipped `reorder` knob is boot-only 0/1, default 0; split mode resolves it to 0 (`src/core/config.h:387`, `:437`, `src/main.cc:192`). Fused boot selects the isolated R7 runtime at `src/core/reorder.cc:3768`. Its shadow scheduler ranks unshadowed short tasks, long tasks, then shadowed short tasks; only a connection's head is eligible, and an oldest-task quota bounds selection delay in picks (`src/core/reorder.h:363`, `:401`, `:406`, `:441`). This is not a wall-time bound. Submission rejects batches larger than BatchOps (`src/core/reorder.h:452`); the deleted scheduler's stack-overwrite description is not a current finding.

See [round3-read/controllers.md, section A](../round3-read/controllers.md#a-as-built) for the two controllers. Independent `key-lb` and `client-lb` default to 1; `flip-auto` defaults to 0 (`src/core/config.h:306`, `:314`). LB moves shards or connections at a fixed role split after sustained evidence, using IO/EX or client drain stages (`src/core/weighted_lb.h:25`, `src/core/server.h:1272`, `:1496`). The automatic role controller runs in 2s, estimates demand, checks expected benefit against movement cost, and verifies or reverts a move (`src/core/flipctl.cc:836`, `:1057`, `src/core/flip_policy.h:478`). LB has no corresponding verify/revert outcome loop; do not attribute that FLIP mechanism to it. Operator spellings/defaults are in [CONFIGURATION.md](docs/CONFIGURATION.md); ownership and read-local paths are in [ARCHITECTURE.md](docs/ARCHITECTURE.md).
